这里是「随便写写」，一个用**通用模板**生成的单页：在控制台「单页」里新建一个文件、写上标题和正文，构建完它就自己长成一个页面了，不用再写任何代码。

## 这个页面有什么

- 正文是 Markdown，跟文章页同款渲染：**加粗**、列表、引用都行，==高亮== 也有效
- 代码块带语法高亮（就是文章里那套配色）：

```js
// 举个例子
const page = createPage("notes");
page.render(); // 页面就出来了
```

- 底部自带评论区，开关在控制台「单页」页顶部的「💬 评论区开关」卡里，不想让人评论随时关

## 以后这里放什么

还没想好。可能就是些不值得单独成文的东西：临时记录、清单、碎碎念plus。先把坑占上。

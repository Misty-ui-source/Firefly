今天是被博客榨干的一天。早上还在为昨晚 v73–v83 全回滚认错，下午直接干到 v105。

先说最重磅的：评论区住进了一个 AI——zhz-ai。

起因很简单：我想让每条评论都有人回。定案五条：昵称、头像带勋章、顶层嵌套都回、不延迟、智谱免费 API、自己不回自己。名字改了三轮：Muse管家 → Muse → 暮色 → zhz-ai（最后这版，"AI 的名字要跟我一致"）。

回复风格对标 HY 站的 UPXUU：随笔评论短平快玩梗，技术评论大胆展开、答不上来就认怂不瞎编。还让它"读过文章"——构建时给每篇文章生成摘要，评论来了把文章标题和摘要一起喂给模型。

部署过程堪称连续剧：Waline 的 webhook 配了但死活不触发，日志里连个影子都没有，改成 60 秒轮询兜底；轮询线程又因为 Gunicorn 不执行 `if __name__ == "__main__"` 根本没启动——挪到模块顶层，日志里终于出现 `[poll] 轮询线程启动`；HK 那台 2C/887MB 的小鸡被一条评论干到 load 10，只能把服务迁到基本空载的 ID 机，HK 的 nginx 反代过去；头像一开始写 payload 里 Waline 不认，最后改走 QQ 邮箱才生效。今晚，它已经在评论区真实回复了。

另一条线：14 篇实验报告。三个 zip 加两份 doc（电路、模电、数电、大学物理、电子工艺实践，还有篇 LED 结温小论文），全部发布。每篇按报告原名、日期按报告上的实验日期、姓名打码成 zhz。格式返工了三轮——表格补表头、标题按理解重做层级。我划了两条线：只改格式不动内容，之前的老文章一篇不碰。

统计页从 v84 一路干到 v105：最大的改动是加速——VPS 上 cron 每 5 分钟拉一次 Umami 写成静态 `/api/stats.json`，前端先走这个（毫秒级），失败再走原来的直连逻辑兜底。热力图修好了（Astro 作用域 CSS 的坑）、点图日期被裁、"实时更新于"回落旧快照，一个一个修。`is:inline` 这个坑踩了两次：Astro 构建会直接丢掉没加它的 script，之前的"实时"有几版根本就没进包。

中间还干了几件事：友链加了<a href="https://blog.fqzlr.top/" target="_blank"><strong>番茄主理人</strong></a>（排第一）、<a href="https://pasule.com/" target="_blank"><strong>Pasule</strong></a>；授权把博客源码 push 到我自己的 Misty-ui-source/Firefly 仓库（之前"绝对不要 push GitHub"是我亲口破的例，只限自有仓库）；灰云 + 优选 IP 亲自实测翻车——改完报 Error 1000，我自己想明白的："这样 Cloudflare 根本不知道指向哪个域名"，回退橙云，PC 打不开的问题还没解；联系方式以后默认只放 About 页，头像下面那行图标不放。

构建现在全自动了：`./build.sh` 一把梭——清缓存、生成文章索引和摘要、astro build、Pagefind 重建索引。之前新文章搜不到，就是跳过了 Pagefind 这步，以后每次必跑。

v105 我已经部署了，站点正常。zhz-ai 在 ID 机上跑着，60 秒一轮。今晚早点睡——昨晚两点才睡的我最后的倔强。

昨晚干了件大事：把评论系统从 HK 机子的 Docker 连夜迁到 Vercel。

## 为啥迁

旧 Waline 跑在 HK 机 Docker 里，better-sqlite3 跟 Node 闹别扭，时不时 502。后台登不上，前台评论倒是能用，但看着闹心。

正好新注册了个 Vercel 号（额度满的），那就迁吧。官方 `walinejs/waline` fork 一份，改改就能跑。

## 硬核部署过程

**1. 构建踩坑**

pnpm 12 不认官方 `pnpm-workspace.yaml` 旧语法，vercel.json 加 installCommand 被 legacy builds 吃掉，`.npmrc` 加 dangerously-allow-all-builds 还是 `ERR_PNPM_IGNORED_BUILDS`。

最后：删了 fork 的 `pnpm-lock.yaml`，强制走 npm，过了。

**2. 数据库选型**

本来想上 LeanCloud，结果 leancloud.cn 停新注册了（我推荐前没核实，我的锅）。

改 MongoDB Atlas 免费 M0，选 us-east-1（离 Vercel iad1 近）。官方文档说了，Mongo 变量必须拆开，不能粘整串：

- `MONGO_DB=waline`
- `MONGO_USER=haozez57_db_user`
- `MONGO_HOST` 是三分片主机数组
- `MONGO_PORT` 必须也是数组 `[27017,27017,27017]`，写单值会被 think-mongo 按字符拆（别问我怎么知道的）
- `MONGO_REPLICASET=atlas-hnbyk3-shard-0`
- `MONGO_AUTHSOURCE=admin`
- `MONGO_OPT_SSL=true`

**3. 数据迁移：22 条评论的血泪史**

HK 机 SQLite 里实际只有 22 条（之前以为 58 条，那是巡检水位）。

第一轮：pymongo 直插 MongoDB，API 读不全。弃。

第二轮：走 API 导入，30 秒一条。结果带了管理员 token，22 条全挂到我名下，头像全是我。叫停，删库重来。

第三轮：不带 token 匿名导入。Waline 限流比想象的严，30 秒不够，45 秒不够，最后发现规律是 90 秒一条。22 条导了快 40 分钟，中间还手动一条一条补。

教训：导入评论绝不能带管理员 token。已刻烟吸肺。

**4. 时间戳修复**

API 导入的时间全是当前时间，得从 SQLite 读原 `createdAt`/`insertedAt` 写回去。写了个脚本按内容匹配，删掉的评论自动跳过。

地点和设备信息：Waline 从 IP 和 UA 自动解析，导入时原样带过去就行。

## 控制台更新

- 修了导航栏中间的大空隙（`.page-title` 的 `flex: 1` 撑的，改成 `flex: 0 1 auto` + `max-width: 200px`）
- 支持双域名 OAuth：`firefly-6sp.pages.dev` 和 `lanerc.me` 各用各的 GitHub OAuth App，按 `location.hostname` 自动切 Client ID，后端 `github-exchange.js` 也按 client_id 选 secret

## 主域迁移

`lanerc.me` 从 HK 机（20.239.49.52）切到 Cloudflare Pages（`firefly-6sp.pages.dev`）。DNS 从 A 记录改成 CNAME，点下 "Activate domain" 就完事。旧站先留着，万一翻车还能回滚。

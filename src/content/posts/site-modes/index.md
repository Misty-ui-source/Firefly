站点主题用久了会腻。一套皮肤看几天，再好看也忍不住折腾着想换；可真要换主题，文章、评论、配置全得搬家，伤筋动骨。

所以我最后没换主题，而是给本站做了**站点形态**：同一套页面、同一份内容，四张完全不同的脸，右上角调色板里随时切，刷新不丢。我可以设一个默认，访客切走的以访客自己选的为准。

这篇把四种形态讲清楚，再讲它们能跟哪些东西搭配，最后给六套我实际用过的推荐组合。想抄作业的可以直接跳到第三节。

## 一、先看效果：四种形态

| 形态 | 视觉语言 | 一句话印象 | 出处 |
| --- | --- | --- | --- |
| 华彩 | 3px 纯黑粗边框 + 白卡 | 贴纸感，热闹，全功能 | 本站默认，**站长**风格 |
| 素简 | 简洁导航 + 大留白 | 专注阅读，像纸 | 参考**朝朝听雨**的 **Pure** 形态 |
| 谐彩 | Material 3 色阶 · 无边框柔影 | 安卓原生应用的味道 | 参考 **Shirone** 主题 |
| 顽彩 | 玩具积木粗野风 · 粗描边硬阴影 | 童年杂货铺 | 参考 **UpXuu** 的 **xuhome** |

四个形态气质完全是四个方向：华彩艳、素简素、谐彩和、顽彩野。

细节上各有各的执念。素简把调色板都精简了，只留下形态、字体和文章布局——壁纸和特效在这个形态下本来就不生效，留着纯属占地方；谐彩把边框全撤了，页面靠一整套色阶梯分层，主色跟着色相滑杆整套重新推导；顽彩反着来，描边按 4 / 3 / 2 / 1.5px 分级、圆角统一 4px、阴影是实打实的硬 offset，连 Logo 都是一块斜切的浅黄砖。

## 二、能搭的维度

形态只是脸。真正让组合爆炸的是下面这些维度，它们大多互相独立：

| 维度 | 可选 |
| --- | --- |
| 壁纸模式 | 横幅 / 全屏 / 覆盖透明，每个模式还能单独开关轮播 |
| 导航栏样式 | 四款，独立于形态切换 |
| 主题色 | 色相滑杆整圈（谐彩另有九种 Material 色彩风格、两代色彩规范） |
| 明暗 | 亮 / 暗，每个形态都有自己的暗色值 |
| 字体 | 字体库十余款；素简有专属字体菜单，控制台可管 |
| 特效 | 樱花、萤火虫、雪、雨，可单开可全关 |
| 壁纸质感 | 覆盖透明的透明度与模糊、谐彩的纹理（六种预设 + 不透明度） |

四种形态 × 三种壁纸 × 四款导航 × 明暗 × 字体特效，保守算也是几千种组合（本人数学很好）。当然大部分组合没人会用，下面这六套是我自己留过的。

## 三、推荐搭配

1. **个人默认（华彩 · 横幅轮播）**
华彩 + 横幅壁纸开轮播 + 色相 174 青绿 + 樱花开。就是你现在打开本站看到的样子，热闹、信息量大，适合首页刷存在感。

2. **深夜读长文（素简 · 暗色）**
素简 + 暗色 + 朱雀仿宋 + 特效全关（或加萤火虫）。导航缩到最简，正文是仿宋，半夜看长文眼睛不累。素简的暗色是我专门调的：夜晚模式下每个功能都必须看得见，这是底线。

3. **安卓原生味（谐彩 · 覆盖透明）**
谐彩 + 色彩风格选 Vibrant + 色相拉到 200 左右 + 背景纹理选圆点 + 壁纸覆盖透明。毛玻璃顶栏加上色阶梯卡片，整个站像一个 Material You 应用，设置页尤其像。

4. **童年杂货铺（顽彩 · 亮色）**
顽彩 + 亮色 + 中文圆体。顽彩的壁纸不走图库，是一张草地小狗插画铺满，配上硬阴影和斜切砖块 Logo，像小时候文具店的包装纸。这个形态只在亮色下最对味，暗色是深蓝夜空版，另一种气质。

5. **玻璃感拉满（华彩 · 覆盖透明）**
华彩 + 覆盖透明 + 模糊 10 + 透明度拉低。卡片全是毛玻璃，壁纸在底下流动。代价是费性能，老设备慎用——所以覆盖透明的轮播默认是关的（之前不小心打开轮播，现关闭了），想体验的要自己开。

6. **一张白纸（素简 · 亮色）**
素简 + 亮色 + 系统默认字体 + 壁纸关。什么都没有，就剩字。写东西、贴代码的时候我最常用这套自检排版：任何花哨都藏不住，格式有问题一眼看见。

搭配的入口都在右上角调色板里，改完即时生效、自动记住，不用刷新试错。

## 四、实现细节

机制不复杂：**一套 DOM，属性开关**。

页面根元素上挂一个形态属性，四套样式各自收在一个文件里、用属性选择器圈起来，互不干扰。切换时只改属性和几个 CSS 变量，不重渲染、不闪烁。首帧由一段内联脚本在页面画出来之前就把属性定好，所以不会先闪一下默认形态再跳过去。

跟导航栏四款样式走的是同一套底层——那是更早做的功能，形态系统算是它的放大版。访客的选择存浏览器本地，我在控制台设的是默认值：没动过的访客用默认，动过的以自己的为准。这条优先级后面还踩了个坑，第五节会说。

控制台那边同步做了两件事：主题页能设全站默认形态；顽彩那张专属壁纸进了图片页，能换图、能恢复默认，不用改代码。

## 五、踩到的坑

**一：暗色下大批文字发黑。**
现象：切到暗色，卡片里的文字还是黑的，黑底黑字全灭，陆续被我自己在真机上抓出一百多处。
原因：很多卡片只有背景色、没有前景色，文字靠继承，而暗色下继承到的默认色还是黑。
修法：给卡片组件钉死暗色前景色，再让AI写了个扫描脚本，每次构建后把全站页面 × 手机桌面 × 全部形态扫一遍对比度，有问题先修再发。
教训：跨明暗的组件别靠继承吃饭，颜色要自带。

**二：全屏切覆盖透明，图不换。**
现象：从全屏模式切到覆盖透明，还是全屏那张图压着；反过来切却正常。
原因：三组壁纸各自记着「当前张」，切模式只给新组打标记、旧组没清；标记层级一样，谁在页面结构里排最后谁赢，全屏组正好排最后。
修法：切模式（包括屏幕宽窄跨断点）时，先把当前组之外的标记全清掉再点亮新组。
教训：状态切换先清场，再点灯。

**三：调色板的轮播开关管不住站点。**
现象：访客在调色板里关了轮播，刷新后还在轮播。
原因：判定顺序反了——脚本先看控制台的分模式默认，访客的显式设置被压在后面，等于白关。
修法：顺序反过来，访客明确动过以访客为准，没动过才用控制台默认；顺手把覆盖透明模式下缺席的壁纸设置区也补上了。
教训：默认值的职责是兜底，不是抢方向盘。

**四：顽彩壁纸的地址传不进样式。**
现象：壁纸地址写在页面元素的样式属性里，看着没毛病，实际渲染出来是坏的，控制台换图永远不生效、只有默认图能显示。
原因：构建工具不会插值属性里的模板写法，源码长得对、产物是错的。
修法：整个属性改成正经的表达式写法，顺带把同属性里几个一直靠 CSS 兜底值撑着的变量也扶正了，数值和运行时设的完全一致、观感没变。
教训：验证要看构建产物，别信源码的长相。

## 六、最后

回头看，四种形态真正花时间的不是皮肤本身：

- 机制只有一套——属性开关加变量，形态再多也不互相污染；
- 优先级只有一条——访客的显式选择永远压过站点默认；
- 守门的只有一件事——每次构建后全站扫暗色对比度，干净了才发；
- 剩下全是坑，而且都是「本地看着没问题、换个形态或换台设备就崩」的那种。

所以如果你也想给自己的站加形态，我的建议是先把切换机制和守门扫描做出来，皮肤反而是最不急的——反正第一版皮肤，几个月后你照样会腻，然后你就会像我一样，做第二、第三、第四种。

## 一、写卡流程（Android）

1. 小白卡插入安卓手机卡槽。
2. 打开 EasyEUICC → 右上角菜单 → **兼容性检查**，通过后重启 App。
3. 右下角 **“+”** → 选择’二维码写入‘，“手动输入”或“从剪贴板读取”。
4. 粘贴 **`LPA:1$...`** 格式激活码。
5. 写入完成后，点卡片菜单 → **启用**，等待信号出现。

**注意：**
- 激活码必须以 `LPA:1$` 开头。
- EasyEUICC 只能操作小白卡，管不了手机自带 eSIM。
- 写卡后建议先关闭数据漫游。

## 二、有信号但收不到短信？

### 1. 先确认信号
- 看状态栏是否有 **“R”** 和 4G/5G。
- 完全无信号 → 可能是运营商限制，联系卖家。
* 成功标志可以看屏幕左上栏：
![](./2.jpg)
### 2. 检查短信中心号码（SMSC）
- 路径：`设置 → 关于手机 → SIM卡状态 → 短信中心号码`
- 常见正确值示例：**`+37256100020`**
- 保持默认也可以
- 号码错误会导致短信收发全废。

### 3. 检查拦截与默认卡
- 短信 App 的“拦截记录/垃圾箱”翻一翻。
- `设置 → 移动网络 → SIM卡管理`，默认短信卡切到小白卡。

### 4. 手动选网
- 关闭“自动选择”，手动搜索运营商，选信号最好的，重启手机。

### 5. 平台风控（重点）
- 官网测试短信能收到，但小红书/Telegram/Google 等收不到。
- 原因：平台对境外号段、虚拟运营商号有风控，**从源头不下发**。
- 平台提示“需要 1–2 天设置”是风控观察期，如果只能收到卖家发来的短信其他的收不到的话，建议等满 24 小时再试，别频繁点。
- 换干净节点有时也有帮助。

## 三、移动数据与漫游

- 移动数据总开关关闭时，即使有信号也可能收不到短信。
- 打开数据，默认上网卡选小白卡。
- **但要注意流量费**：余额低于 0.1 欧会直接断网，国内建议切回国内卡上网，小白卡只收短信。
- 显示“无法识别号码”是正常现象（未写入 MSISDN），不影响收发短信。

## 四、误删 Profile 昵称怎么办

- 只是删昵称：EasyEUICC 里信息还在，不影响使用。
- 可在 EasyEUICC 菜单里 **重命名/编辑** 改回来。
- 确认 Profile 状态是 **“已启用”**。
- `设置 → 移动网络 → SIM卡管理` 里确认开关打开，重启手机试试。
- 真正删除 Profile 后旧激活码会失效，需联系客服重新发码。

## 五、iOS 能用 EasyEUICC 吗？

**不能。EasyEUICC 没有 iOS 版。**

替代方案：
1. **纯 iPhone**：买 USB-C 读卡器或蓝牙 eLPA 读卡器，配合 **9eSIM LPA** 或 **NekokoLPA** App 使用。
2. **安卓写卡 + iPhone 用卡**：用安卓机写好，拔卡插进 iPhone，通过 **STK 菜单**切号。

**建议**：有安卓备用机的话，第二种最省事。
